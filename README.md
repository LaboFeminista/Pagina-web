# Pagina-web
Web del centro cultural de la mujer de Latina

RAMAS GIT
-	Main (principal)
-	desarrollo
    -	tarea/nombredesarrolladora-tarea
 
Main --> desarrollo --> tarea/nombredesarrolladora_tarea

De tarea/nombredesarrolladora_tarea se hacer merge a desarrollo y de desarrollo se hace merge a main. 


ARQUITECTURA DE POYECTO BACK CON DJANDO Y API REST
-	Urls.py: las urls que unen la REST API con el front.
-	Settings.py: la configuración
-	Serializers.py: alberga los Serializadores (Serializers), que actúan como los "traductores" y "controladores de seguridad" de tu API.
-	Models: estructura de las tablas de la base de datos. 


Para usar PostgreSQL
